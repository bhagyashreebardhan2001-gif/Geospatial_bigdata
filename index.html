San Francisco Commute Flow Dashboard

Big Data Visualization in Geoinformatics (Exercise 5) | BVIEER

Project Description: This interactive spatial dashboard presents commuting patterns in San Francisco. The 3D Arc Map links home locations (orange-red) to destination work coordinates (green). Below/beside, the distribution chart displays the relative frequency of route sizes.
